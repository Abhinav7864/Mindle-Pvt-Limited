# Amplemarket Website — UI/UX Design Analysis (`design.md`)

> **Website:** https://www.amplemarket.com/

## 1. Project Overview

Amplemarket is a B2B SaaS platform that provides AI-powered outbound sales, lead generation, multichannel engagement, and sales intelligence. The website is designed to convert visitors into demo requests while educating them about the product ecosystem.

---

# 2. Design Goals

## Business Goals

- Generate qualified demo bookings
- Build trust through customer success
- Showcase AI capabilities
- Position Amplemarket as an all-in-one sales platform
- Encourage product exploration

## User Goals

- Understand what the product does
- Discover features quickly
- Compare solutions
- View pricing/demo options
- Validate credibility

# 5. Navigation Analysis

- Sticky top navigation
- Mega menus for products and solutions
- Persistent primary CTA
- Login separated from conversion CTA

**Strengths**
- Familiar SaaS pattern
- Easy discoverability
- Clear hierarchy

**Weaknesses**
- Mega menus contain many options
- Can overwhelm first-time users

# 8. Typography

## Typeface
Modern geometric sans-serif (similar to Inter/SF Pro/Manrope).

## Hierarchy

| Element | Weight | Size |
|----------|--------|------|
| H1 | Bold | 52–64 px |
| H2 | Bold | 36–44 px |
| H3 | Semibold | 24–30 px |
| Body | Regular | 16–18 px |
| Small | Regular | 14 px |

Characteristics:
- High readability
- Short paragraphs
- Strong hierarchy
- Consistent spacing

# 19. Key Takeaways

Amplemarket demonstrates a mature enterprise SaaS design system. It emphasizes product storytelling, trust, and conversion through strong typography, generous whitespace, consistent components, and repeated calls-to-action. The experience is polished and optimized for lead generation while remaining easy to scan despite its content-rich layout.
